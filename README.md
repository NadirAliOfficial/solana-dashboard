# ◎ Solana Token Dashboard

A real-time dashboard for the **top 20 Solana tokens** by 24-hour trading volume — built with React + Vite.

## Features

- **Live token data** — price, 24h change, volume, market cap, high/low
- **SOL price tracker** in the header with 24h % change
- **Social media icons** — Twitter/X, Telegram, Discord, Website per token
- **One-click buy** via Jupiter DEX aggregator
- **Search & sort** by volume, market cap, price, or 24h change
- **Auto-refresh** every 60 seconds
- Dark theme with Solana's purple/green palette

## Getting Started

```bash
git clone https://github.com/NadirAliOfficial/solana-dashboard.git
cd solana-dashboard
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173)

## Tech Stack

| Layer | Tool |
|-------|------|
| Framework | React 18 |
| Bundler | Vite 5 |
| Market Data | CoinGecko API (free tier) |
| Buy Integration | Jupiter Aggregator |
| Styling | Plain CSS (dark theme) |

## Data Sources

- **[CoinGecko](https://www.coingecko.com/)** — token prices, volume, market cap
- **[Jupiter](https://jup.ag/)** — DEX aggregator for buying tokens
